# 👟 Shoe Hut — Footwear E-Commerce Website

A modern and responsive footwear e-commerce frontend designed to deliver a smooth and engaging online shopping experience.

Shoe Hut combines a clean interface with practical shopping features, making it easy for users to explore footwear, discover products, manage their wishlist, and interact with a shopping cart.

## ✨ Features

- **Modern UI:** Clean, minimal, and user-friendly design.
- **Responsive Design:** Optimized for desktop, tablet, and mobile screens.
- **Product Listing:** Browse a collection of footwear products.
- **Search Functionality:** Find products quickly.
- **Filtering & Sorting:** Explore products using available filters and sorting options.
- **Product Details:** View individual product information.
- **Shopping Cart:** Add and manage items in the cart.
- **Wishlist:** Save favorite products.
- **Checkout Demo:** Experience a frontend checkout flow.
- **Reusable Components:** Maintainable and organized React components.

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React

- Mock Product Data

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd shoe-hut
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛍️ Project Scope

Shoe Hut is a frontend-focused project that demonstrates e-commerce interface development and client-side interactions.

**Important:** Product data is mocked, and cart or wishlist persistence uses browser local storage where implemented. Authentication, backend services, inventory management, and real payment processing are not included unless separately integrated.
