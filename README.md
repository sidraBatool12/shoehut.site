# Shoehut — Frontend-only footwear store

A premium editorial footwear e-commerce UI built with Next.js App Router, React, TypeScript, Tailwind CSS, and Lucide React.

## Run locally
1. Install Node.js 20+.
2. In this folder run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

## Notes
- All products are local mock data in `lib/products.ts`.
- Cart and wishlist persist in browser `localStorage`.
- Checkout, contact, newsletter, login, and signup are demonstrations only. No backend, authentication, API routes, or payment processing exists.
- Product imagery is loaded from Unsplash source URLs and requires an internet connection.
